## 2. EventGraph 흐름 분석 (BlueprintUpdateAnimation)

```
Event BlueprintUpdateAnimation (Delta Time X)
  │
  └─[Get Owning Component] → Return Value (SkeletalMeshComponent)
       │
       └─ Component Tags → GET [0] → Tag (FName)
            │
            └─ IKRetargeter_Map.FIND(Tag) → UIKRetargeter*
                 │
                 └─ SET IKRetargeter
                      │
                      └─[Copy Retarget Profile from Retarget Asset]
                           In Retarget Asset : IKRetargeter
                           → Return Value (FRetargetProfile)
                                │
                                └─ SET RetargetProfile
                                     │
                                     └─[UpdateRetargetProfile]
                                          Target       : self
                                          Input Profile: RetargetProfile
                                          → Return Value (AnimGraph로 전달)
```

**핵심**: 매 프레임 ComponentTags[0] 기반으로 IKRetargeter를 결정하고, 에셋 기본값으로 RetargetProfile을 리셋 후 커브 Lerp 적용.

### IKRetargeter_Map 실제 데이터 (7개 항목)

| ComponentTag (Key, FName) | IKRetargeter 에셋 (Value) |
|--------------------------|--------------------------|
| `RTG_UE4_to_UE4_Mannequin` | RTG_UE_...nequin 에셋 |
| `RTG_UEFN_to_UE5_Mannequin` | RTG_UE_...nequin 에셋 |
| `RTG_UEFN_to_Echo` | RTG_UE_...o_Echo 에셋 |
| `RTG_UEFN_to_TwinBlast` | RTG_UE_...inBlast 에셋 |
| `RTG_UEFN_to_Metahuman` (nrw) | RTG_UE_...an_nrw 에셋 |
| `RTG_UEFN_to_Metahuman` (crw) | RTG_U_...an_crw 에셋 |
| `RTG_AutoGenerated_Shinbi` | RTG_Aut...Shinbi 에셋 |

> SkeletalMesh의 ComponentTags[0] 값 = 사용할 IKRetargeter 에셋명과 동일한 FName

## 3. UpdateRetargetProfile 함수 흐름 분석

### 3.1 함수 시그니처
```
Input  : Input Profile (Retarget Profile — by ref)
Output : Return Value  (Retarget Profile — 수정된 프로파일 반환)
```

### 3.2 전체 Sequence 구조

```
UpdateRetargetProfile
  └─ Sequence
       ├─ Then 0 : 컨트롤러 획득 + 초기 체인 배열 저장
       ├─ Then 1 : For Each Loop — 체인별 커브 Lerp 적용
       └─ Then 2 : 수정된 설정 저장 + Return
```

### 3.3 ChainCurveMap 로컬 변수 실제 데이터

**타입**: `TMap<Name, Name>` — (체인명 → 커브명)  
**스코프**: `UpdateRetargetProfile` 함수의 로컬 변수 (Default Value로 고정값 설정)

| 체인명 (Key) | 커브명 (Value) |
|-------------|--------------|
| `RightArm` | `Retarget_Hand_R_BlendToSource` |
| `LeftArm` | `Retarget_Hand_L_BlendToSource` |

### 3.4 Then 1 — 체인별 Lerp 처리

```
For Each Loop (Chains to Set)
  └─ Break FRetargetIKChainSettings
       ├─ Target Chain Name → ChainCurveMap.CONTAINS? → Branch
       │
       ├─ [True] ChainCurveMap.FIND → CurveName
       │          GetCurveValue(CurveName) → Alpha
       │          Lerp(BlendToSource, 1.0f, Alpha)       → Make 노드
       │          Lerp(Vector)(BTS_Weights, (0,0,0), Alpha) → Make 노드
       │          Set Array Elem (수정된 체인)
       │
       └─ [False] 아무것도 하지 않음 (원본 유지)
```

## 4. 5.7 → 5.8 API 변경 매핑

### 4.1 Op 이름 / 컨트롤러 클래스

| 항목 | 5.7 BP | 5.8 C++ |
|------|--------|---------|
| Op Name | `"Retarget IK Goals"` | `"Blend to Source"` |
| 컨트롤러 클래스 | `UIKRetargetIKChainsController` | `UIKRetargetBlendToSourceController` |
| GetSettings 반환 | `FRetargetIKChainsOpSettings` | `FIKRetargetBlendToSourceOpSettings` |
| Chains 배열 요소 | `FRetargetIKChainSettings` | `FIKRetargetBlendToSourceChainSettings` |

### 4.2 체인 구조체 필드 매핑

| BP 5.7 필드 | C++ 5.8 필드 | Lerp 처리 |
|------------|-------------|-----------|
| Target Chain Name | `TargetChainName` | passthrough |
| Enable IK | ❌ 제거됨 | N/A |
| Blend To Source | `BlendToSource` | **Lerp(현재, 1.0f, α)** |
| Blend To Source Weights | `TranslationPerAxisAlpha` | **Lerp(현재, ZeroVector, α)** |
| Blend To Source Translation | `TranslationAlpha` | passthrough |
| Blend To Source Rotation | `RotationAlpha` | passthrough |
| Apply Pelvis Offset To Source Goals | `ApplyPelvisOffset` | passthrough |
| Static Offset / Local / Rotation | ❌ 제거됨 | N/A |
| Scale Vertical | ❌ 제거됨 | N/A |
| Extension | ❌ 제거됨 | N/A |

### 5.3 링커 우회 전략 (MinimalAPI 문제)

`UIKRetargetBlendToSourceController`는 `UCLASS(MinimalAPI)`로 선언되어 `GetSettings()` / `SetSettings()`가 DLL 외부로 export되지 않는다.  
`URetargetProfileLibrary::GetOpControllerFromRetargetProfile`도 마찬가지.

**해결**: 컨트롤러를 경유하지 않고 `FRetargetProfile::RetargetOpProfiles` 내부 `FInstancedStruct`를 포인터로 직접 수정.

```cpp
// ❌ 값 복사 → copy ctor/dtor → vtable 참조 → LNK2001
FIKRetargetBlendToSourceOpSettings Settings = Ctrl->GetSettings();

// ✅ 포인터 직접 접근 — 헤더 inline 템플릿, vtable 참조 없음
TArray<FIKRetargetBlendToSourceOpSettings*> MatchingOps;
RetargetProfile.GetOpSettingsByTypeInProfile<FIKRetargetBlendToSourceOpSettings>(MatchingOps);
// in-place 수정 → SetSettings 불필요
```

### 5.4 최종 헤더 (ExRetargetAnimInstance.h)

```cpp
UCLASS()
class EXCORERUNTIME_API UExRetargetAnimInstance : public UAnimInstance
{
    GENERATED_BODY()
public:
    virtual void NativeInitializeAnimation() override;
    virtual void NativeUpdateAnimation(float DeltaSeconds) override;

    /** AnimGraph RetargetPoseFromMesh "Custom Retarget Profile" 핀에 바인딩 */
    UPROPERTY(BlueprintReadWrite, Category = "Retarget")
    FRetargetProfile RetargetProfile;

    /**
     * ComponentTag명 → IKRetargeter 에셋 매핑 (BP IKRetargeter_Map 대응).
     * ABP Class Defaults에서 설정. 태그 없거나 맵에 없으면 리타겟 안 됨.
     */
    UPROPERTY(EditDefaultsOnly, BlueprintReadOnly, Category = "Retarget")
    TMap<FName, TObjectPtr<UIKRetargeter>> RetargeterAssetMap;

    /**
     * 체인명 → 애니메이션 커브명 매핑 (BP ChainCurveMap 로컬 변수 대응).
     * ABP Class Defaults: RightArm→Retarget_Hand_R_BlendToSource,
     *                     LeftArm→Retarget_Hand_L_BlendToSource
     */
    UPROPERTY(EditDefaultsOnly, BlueprintReadWrite, Category = "Retarget")
    TMap<FName, FName> ChainCurveMap;

    /** 현재 활성 IKRetargeter. 매 프레임 태그 조회로 자동 갱신. Transient. */
    UPROPERTY(BlueprintReadOnly, Transient, Category = "Retarget")
    TObjectPtr<UIKRetargeter> IKRetargeter;

private:
    /** BP EventGraph 이식: ComponentTags[0] → RetargeterAssetMap 조회 → IKRetargeter + FillProfile */
    void UpdateRetargeterFromTag();
    /** BP UpdateRetargetProfile 이식: 체인별 BlendToSource / TranslationPerAxisAlpha Lerp */
    void UpdateBlendToSourceOp();
};
```

### 5.5 최종 구현 (ExRetargetAnimInstance.cpp)

```cpp
void UExRetargetAnimInstance::NativeInitializeAnimation()
{
    Super::NativeInitializeAnimation();
    // IKRetargeter / RetargetProfile 초기화는 매 프레임 UpdateRetargeterFromTag에서 처리
}

void UExRetargetAnimInstance::NativeUpdateAnimation(float DeltaSeconds)
{
    Super::NativeUpdateAnimation(DeltaSeconds);
    UpdateRetargeterFromTag();   // BP EventGraph 이식
    UpdateBlendToSourceOp();     // BP UpdateRetargetProfile 이식
}

void UExRetargetAnimInstance::UpdateRetargeterFromTag()
{
    USkeletalMeshComponent* MeshComp = GetOwningComponent();
    if (!MeshComp || MeshComp->ComponentTags.IsEmpty())
    {
        IKRetargeter = nullptr;
        return;
    }
    const FName Tag = MeshComp->ComponentTags[0];
    TObjectPtr<UIKRetargeter>* Found = RetargeterAssetMap.Find(Tag);
    IKRetargeter = (Found && *Found) ? *Found : nullptr;
    if (IKRetargeter)
    {
        // BP: Copy Retarget Profile from Retarget Asset → SET RetargetProfile
        RetargetProfile.FillProfileWithAssetSettings(IKRetargeter);
    }
}

void UExRetargetAnimInstance::UpdateBlendToSourceOp()
{
    if (!IKRetargeter) return;

    TArray<FIKRetargetBlendToSourceOpSettings*> MatchingOps;
    RetargetProfile.GetOpSettingsByTypeInProfile<FIKRetargetBlendToSourceOpSettings>(MatchingOps);

    for (FIKRetargetBlendToSourceOpSettings* Settings : MatchingOps)
    {
        if (!Settings) continue;
        for (FIKRetargetBlendToSourceChainSettings& Chain : Settings->Chains)
        {
            const FName* CurveName = ChainCurveMap.Find(Chain.TargetChainName);
            if (!CurveName) continue;  // False 분기: 맵에 없는 체인 → 원본 유지

            const float Alpha = GetCurveValue(*CurveName);
            Chain.BlendToSource = FMath::Lerp(Chain.BlendToSource, 1.0, Alpha);
            Chain.TranslationPerAxisAlpha = FMath::Lerp(
                Chain.TranslationPerAxisAlpha, FVector::ZeroVector, static_cast<double>(Alpha));
            // TranslationAlpha, RotationAlpha, ApplyPelvisOffset → passthrough
        }
    }
}
```
