// turbo-all

이 워크플로우는 현재까지 진행된 프로젝트의 변경 사항들을 확정(commit)하고 원격 저장소로 업로드(push)하기 위해 실행됩니다.

1. 시스템 터미널(`run_command` 도구)을 통해 `git add .` 명령을 실행하여 모든 변경 사항을 스테이징(staging)합니다.
2. 현재 작업했던 내용(예: 버그 수정, 파일 변경 등)을 요약하여 적절한 한글 커밋 메시지를 자동 작성하고, `git commit -m "[커밋 메시지]"` 명령을 실행해 커밋합니다. (내용이 명확하지 않을 경우 주인님의 확인을 구합니다.)
3. push 단위는 최소한 각 Plugin단위로 나누어 Push 합니다. 서로 다른 상위 경로의 코드들을 수정된 히스토리가 하나의 커밋 히스토리로 남아있으면 안됩니다.
4. `git push` 명령을 실행하여 원격 저장소로 푸시 작업을 진행합니다.
5. 모든 명령이 성공적으로 완료되면, 주인님께 정중한 한국어로 푸시가 성공적으로 끝났음을 보고합니다.
6. 중간에 실패(예: merge conflict 등)가 발생할 경우, 자체적으로 무단 해결을 시도하지 않고 바로 작업을 멈춘 뒤 주인님께 보고부터 진행합니다.
