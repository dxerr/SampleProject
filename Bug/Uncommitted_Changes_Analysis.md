# Git 미커밋(Uncommitted) 변경 사항 분석 보고서

## 1. 개요
현재 프로젝트(`c:\wz\ExFrameWork`) 내에서 Git에 최신화되지 않은 수정 사항들을 파악하고, 그 핵심 내용을 분석한 결과입니다. 향후 개선 작업을 위해 현재 코드 상태를 점검하는 용도입니다.

## 2. 변경된 주요 파일 및 분석 요약

### 2.1 이동 및 회전 제어 방식 개선 (핵심 변경)
- **대상 파일**: `ExRunnerMovementComponent.cpp`, `ExRunnerMovementComponent.h`
- **변경 사항 상세**:
  1. **정확한 경로 추적 (ForwardDir 개선)**:
     - 기존에 플레이어 컨트롤러 회전값으로 전진 방향을 유추하던 방식에서, **경로 매니저(`PathManager`)에서 플레이어 진행 거리에 따른 방향 데이터를 직접 가져오도록 개선**되었습니다. 이를 통해 무브먼트 컴포넌트가 '경로의 정면(플래인 축)'을 정확히 바라보게 됩니다.
  2. **회전 오작동(Spinning) 버그 해결**:
     - `FInterpTo` 함수를 쓰던 컨트롤러 보간을 **구체적인 최단 거리를 찾는 `FMath::RInterpTo`로 대체**했습니다. 이로써 회전값이 -180도와 180도 경계를 넘을 때 360도로 헛도는 현상이 해결되었습니다.
  3. **좌우 스와이프 입력 방식 누적형으로 변경**:
     - 횡이동 시 목표 Yaw 오프셋이 단순히 비율화된 절대값이 아니라, 사용자의 입력(AxisValue)과 민감도(`RunnerLookSensitivity`)에 비례하여 **지속적으로 누적(+=)되도록 로직이 수정**되었습니다. 조작감이 상대적이고 연속적으로 개선되었습니다.
  4. **다이나믹 회전 보간 스피드**:
     - 급커브(현재 방향과 목표 방향 차이가 15도 이상)일 때 **회전 보간 속도를 1.5 배 증가시켜 코너링 반응성을 크게 향상**시켰습니다.
  5. **충돌하는 강제 위치 조정 로직 삭제**:
     - `AddActorWorldOffset`으로 횡단 오류를 억지로 잡던 코드를 제거하여, 위치 보정이 순수하게 Mover 플러그인의 시뮬레이션 입력(Input) 사이클로 통합되었습니다.

### 2.2 입력(Input) 타입 정밀도 및 구조 최적화
- **대상 파일**: `ExRunnerInputComponent.cpp`, `ExRunnerInputComponent.h`
- **변경 사항 상세**:
  1. **입력 벡터형으로 확장**:
     - 전진 이동(`MoveAction`)과 관련된 주요 함수들의 매개변수가 단순 실수(`float`)에서 벡터(`FVector2D`) 기반으로 변경되었습니다. `InjectInputVectorForAction`을 사용해 (0, 1)의 방향을 확실히 명시하여 엔진 측으로 밀어 넣도록 수정되었습니다.
  2. **Look 액션 델리게이트 구분 형상화**:
     - 시선 이동/조향에 사용하는 `OnLookRequested` 이벤트 전용으로 `FOnRunnerLookRequested(float AxisValue)` 델리게이트형을 새로 정의하여 독립성과 명확성을 확보했습니다.

### 2.3 기타 에셋 및 구성 요소 상태
- **`BP_Shinbi.uasset` (블루프린트 에셋)**: 바이너리 형태가 수정되었습니다. (애니메이션, 컴포넌트 패러미터 등 수정 추측)
- **`Plugins/UnrealCopilot`**: 서브모듈(Submodule)에 수정된 흔적(Modified content/dirty 상태)이 남아있습니다.

## 3. 종합 의견 및 제안
이상의 변경 사항들은 **모바일 조향 조작감 향상 (회전 오작동 수정, 상대 경로 입력 구현, 방향 보간 강화)**을 위한 작업이었음이 명백합니다. 추가 개선을 이어가기 전에 현재 정상적으로 빌드가 되는지 점검하고, 방대한 변경 사항이 한 번에 섞이기 전 해당 내용들을 Git에 리뷰/커밋 해 두시는 것을 권장합니다 (주인님 판단에 따름).
