# [2026-03-23] 코인 스폰 라인 연속성(Continuity) 단절 버그 수정

## 현상 (증상)
- 데이터 에셋에서 `CoinLineSpawnProbability = 1.0`, `CoinLineBreakProbability = 0.0`으로 설정하여 코인이 맵 전체에 끊김 없이 생성되도록 유도했으나, 여전히 코인 라인이 듬성듬성 끊기는 현상 발생.

## 원인 분석
코인 라인이 끊기는 구체적인 원인은 2가지가 중첩되어 있었습니다.

1. **청크 경계의 하드코딩된 여백 (가장 큰 원인)**
   - `SpawnItemsOnChunk` 내부 로직에서 아이템 스폰 가능 구역(`SafeStart`, `SafeEnd`)을 계산할 때, 양 끝단에서 `MinDistanceFromObstacle`(기본 200cm)만큼을 무조건 빼고 계산하고 있었습니다.
   - 이로 인해 이전 청크의 끝부분 200cm와 다음 청크의 시작부분 200cm, 총 **400cm의 거대한 물리적 간격이 매 청크마다 강제**되어 코인이 이어질 수 없었습니다.
2. **`MaxCoinsPerLine` 갯수 제한 및 이월 불가능**
   - 스폰 로직이 청크 단위로 분리되어 있어, 청크가 바뀔 때 남은 거리(간격)를 기억하지 못하고 0부터 다시 시작했습니다.
   - 또한, 데이터 에셋의 `MaxCoinsPerLine` 갯수를 다 소진하면 맵 공간이 남아있더라도 루프를 종료해버려 라인이 끝나버리는 구조였습니다.

## 해결 방법 (수정 내용)
1. **청크 경계 간격 제거 및 이월(Carry-over) 로직 도입**
   - 매 청크마다 양끝을 비우던 `SafeStart`, `SafeEnd` 제약을 풀고, 청크의 처음(0)부터 끝(`ChunkLength`)까지 온전히 코인을 배치할 수 있도록 수정했습니다.
   - `PersistentNextCoinDistance`라는 상태 변수를 도입하여, 청크를 꽉 채우고 남은 여분 간격(`CurrentDistance - ChunkLength`)을 정확하게 다음 청크의 시작 오프셋으로 이월시킵니다. 여러 청크가 지나가도 코인 간의 간격(예: 150cm)이 수학적으로 완벽하게 유지됩니다.
2. **명확한 라인 종료 조건 정립**
   - 코인 갯수 제한(`CoinCount`)을 다 채워서 루프가 끝났거나, 다음 청크가 확률(`CoinLineSpawnProbability`)에서 탈락했을 때만 라인을 강제로 종료(이월 데이터 초기화)하도록 로직을 정리했습니다.

## 결과 및 세팅 가이드
- 이제 `CoinLineSpawnProbability = 1` 이고 `MaxCoinsPerLine`을 매우 높은 값(예: 999)으로 설정하시면, 맵이 끝날 때까지 150cm 간격으로 단 한 번의 끊김도 없이 스폰됩니다!
- 기획적으로 듬성듬성 그룹을 짓고 싶다면 `Min/MaxCoinsPerLine`을 5~10 정도로 설정하시면 됩니다.
