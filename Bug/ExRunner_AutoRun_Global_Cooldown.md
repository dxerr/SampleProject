# [개선 리포트] AutoRun 모드 대각선 동시 오입력 방지 (Global Cooldown) 및 임계치 연동

## 이슈 요약
- 점프(위)나 슬라이딩(아래) 스와이프 시 손가락이 대각선으로 움직일 경우, y축(수직)과 x축(수평) 이동이 아주 찰나의 프레임 차이로 임계치를 넘기게 되어 점프와 차선 변경이 1프레임 내에 동시에 다발적으로 발동하는 오입력 문제가 건의되었습니다.
- 또한 AutoRun의 차선 변경 임계치가 데이터셋(`SwipeActivationPercentage`) 규격을 따르지 않고 `0.5f`로 임의 하드코딩되어 일관성이 결여되어 있었습니다.

## 원인 분석
- `JumpAction`, `SlideAction`, `MoveAction`이 각각 별도의 입력 파이프라인과 개별적인 쿨다운 타이머(`LastJumpTime`, `LastSlideTime`)를 겉돌듯 사용하고 있어, 어느 한 액션이 촉발되어도 타 액션 파이프라인을 잠재울 수단이 없었습니다.

## 해결 방법
1. **데이터셋 임계치 동적 연동**: 하드코딩된 `0.5f` 수치를 폐기하고, InputComponent를 통해 `ExGameModeDataSet`의 `SwipeActivationPercentage` 값을 동적으로 불러와 가로/세로 스와이프 민감도를 완벽히 일치시켰습니다.
2. **글로벌 ActionCooldown (단일 락)**: 기존에 분산되어 있던 `LastJumpTime`과 `LastSlideTime`을 하나의 전역 변수 `LastActionTime`으로 통합했습니다.
3. 점프, 슬라이드, 좌측 이동, 우측 이동 등 어떤 조작이든 **가장 먼저 임계 조건을 통과하는 즉시 락(Global Cooldown)이 걸려**, 설정된 `ActionCooldown`(예: 0.3초) 동안 꼬리를 물고 이어지는 모든 대각선 방향의 오입력 잔동을 완벽하게 생략/무시하도록 조치했습니다.

## 결과
벡터 크기 판별(`Abs(Y)>Abs(X)`)과 더불어 글로벌 쿨다운 시스템이 2중으로 겹쳐, 이제 점프를 뛰는 순간 손가락이 미끄러져 가로 판정을 받더라도 이미 쿨타임 락이 걸려 차선이 무결하게 유지되며, 오직 절도 있는 한 번의 행동만 묵직하게 발동하게 되어 조작 통제감과 안정성이 눈에 띄게 개선되었습니다.
